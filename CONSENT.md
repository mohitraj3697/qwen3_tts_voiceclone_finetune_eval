# Consent & Ethics Notice

## Purpose
This project fine-tunes a text-to-speech model on publicly available research data
for **educational and research purposes only**.

## Dataset
The LJSpeech dataset is **public domain** (Unlicense). The recordings were contributed
to the public domain via the LibriVox project. The text passages are from non-fiction
books published between 1884 and 1964, also in the public domain.

## Restrictions
- **No impersonation:** The outputs of this project must NOT be used to impersonate
  any real person, living or deceased.
- **No commercial voice cloning without consent:** If you adapt this project for
  voice cloning of a real person, you MUST obtain their explicit informed consent.
- **Research only:** This project is intended for learning and research. Any
  deployment or commercial use requires additional ethical review.

## Responsible Use
- Always disclose when audio is AI-generated.
- Do not use generated audio to deceive, defraud, or manipulate.
- Comply with all applicable local laws regarding synthetic media.
